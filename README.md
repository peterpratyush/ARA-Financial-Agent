\# ARA (Autonomous Research Agent)ARA is an intelligent, agentic financial research assistant built using \*\*LangGraph\*\* and \*\*LangChain\*\*. It automates the process of researching stock tickers, performing financial analysis, and synthesizing insights into comprehensive reports.\## Key Features\* \*\*Autonomous Planning:\*\* Automatically creates a research plan based on the ticker provided.\* \*\*State Management:\*\* Uses a graph-based state machine to track research progress, ensuring facts are accumulated and not lost.\* \*\*Self-Healing Execution:\*\* Gracefully handles tool errors and missing data without crashing the entire research process.\* \*\*Conversational Loop:\*\* Supports multi-turn interactions, allowing you to ask follow-up questions about the company being researched.\* \*\*Memory Persistence:\*\* Remembers the context of your research session using LangGraph checkpoints.\## Prerequisites\* \*\*Python 3.10+\*\*\* \*\*Groq API Key:\*\* \[Get one here](https://console.groq.com/) (Used for the LLM).\## Installation1\. \*\*Clone the repository:\*\*&#x20;
